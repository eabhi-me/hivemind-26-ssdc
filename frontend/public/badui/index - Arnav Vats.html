Active Bad UX Anti-Patterns

1. Dodging Login Button: Real login button moves randomly when mouse approaches, and button text dynamically changes ("Login", "Submit", "Maybe?", "Continue").
2. Visual Hierarchy Trap: The big green primary button is actually "CANCEL & RESET", while the actual Login button is tiny and grey.
3. Disappearing Labels: Form field labels vanish completely once fields gain focus or user starts typing.
4. Obstructive Password Toggle: The "Show Password" button sits directly over the input text, obscuring characters.
5. Microscopic Evasive Checkbox: The "Remember Me" checkbox dodge-shifts on hover and has a 4px click area with confusing double-negative labeling.
6. Far-Away Vague Errors: Error messages trigger in the top-right corner far away from inputs with vague messages ("Something went wrong", "Unexpected input").
7. Random Inactivity Field Wiping: Unfocusing input fields has a random chance to auto-clear typed text.
8. Cryptic Interactive CAPTCHA: Requires choosing prime numbers in ascending order, resetting on minor mistakes.
9. Double Confirmation Loop: Triggers nested/layered modal confirmations with reversed button styling.
10. Artificial Delay & Fake Session Expiry: Long fake progress bar loading (4s) which fails on the first attempt with "Session Expired" before eventual success.
